# html2text

This is a *custom fork* of [jaytaylor/html2text](https://github.com/jaytaylor/html2text) tailored towards usage in [feed2imap-go](https://github.com/Necoro/feed2imap-go).

You are free to use it, but I make heavy use of force-pushes, so be warned.

Changes incorporated in this branch:

* go.mod support ([PR #42](https://github.com/jaytaylor/html2text/pull/42))
* citation style links ([PR #41](https://github.com/jaytaylor/html2text/pull/41))
* Support for tablewriter v1.0.0 ([PR #68](https://github.com/jaytaylor/html2text/pull/68))
* Removed cmd/html2text
* Renamed to Necoro/html2text to avoid problems in downstream
